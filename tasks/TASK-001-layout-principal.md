# TASK-001 - Layout principal

## Objetivo

Crear la estructura visual inicial de LogSentinel.

## Requisitos

- Sidebar izquierda.
- Header superior.
- Área principal.
- Navegación responsive.

## Sidebar

Debe incluir:

- Dashboard.
- Logs.
- Incidentes.
- Aplicaciones.
- Usuarios.
- Alertas.
- Configuración.

## Restricciones

- No implementar backend.
- No consumir APIs reales.
- Utilizar componentes reutilizables.

## Criterios de aceptación

- La aplicación compila.
- Las rutas principales existen.
- No hay errores de TypeScript.
- El diseño funciona correctamente en desktop.
