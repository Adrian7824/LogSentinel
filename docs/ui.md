# Especificación UI

## Estilo general

Dashboard técnico, moderno y limpio.

Características:

- Jerarquía visual clara.
- Navegación lateral.
- Header superior.
- Tarjetas de métricas.
- Tablas legibles.
- Gráficos orientados a observabilidad.
- Estados y severidades fácilmente distinguibles.
- Diseño responsive.

## Navegación principal

- Dashboard
- Logs
- Incidentes
- Aplicaciones
- Usuarios
- Alertas
- Configuración

## Dashboard

Debe considerar:

- Logs procesados.
- Errores detectados.
- Aplicaciones monitoreadas.
- Usuarios activos.
- Incidentes abiertos.

## Gráficos sugeridos

- Logs por minuto.
- Errores por aplicación.
- Distribución por severidad.
- Tiempo de respuesta.
- Actividad de usuarios.

## Tabla de eventos recientes

Columnas sugeridas:

- Fecha/hora.
- Aplicación.
- Severidad.
- Mensaje.
- Usuario.
- Estado.

## Estados de severidad

- INFO
- WARNING
- ERROR
- CRITICAL

## Diseño

Evitar interfaces excesivamente cargadas. La información crítica debe poder identificarse rápidamente.
