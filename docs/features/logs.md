# Feature - Logs

## Objetivo

Permitir explorar y diagnosticar eventos generados por las aplicaciones.

## Funciones

- Búsqueda de texto.
- Filtrado por severidad.
- Filtrado por aplicación.
- Filtrado por fecha.
- Visualización de metadata.
- Visualización de trace_id.
- Navegación a incidentes relacionados.
