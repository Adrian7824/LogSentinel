# Feature - Dashboard

## Objetivo

Proporcionar una vista inmediata del estado de los sistemas monitoreados.

## Componentes

- KPI de logs procesados.
- KPI de errores.
- KPI de incidentes.
- KPI de aplicaciones.
- Gráfico de logs por tiempo.
- Distribución de severidad.
- Tabla de eventos recientes.

## Interacciones

- Cambiar rango temporal.
- Filtrar por aplicación.
- Navegar hacia logs o incidentes relacionados.
