# Requisitos

## Requisitos funcionales

### RF-01 Dashboard
Mostrar métricas principales del sistema.

### RF-02 Logs
Permitir visualizar, buscar y filtrar logs.

### RF-03 Incidentes
Registrar y consultar incidentes detectados.

### RF-04 Aplicaciones
Mostrar aplicaciones o servicios monitoreados.

### RF-05 Usuarios
Permitir analizar actividad asociada a usuarios cuando exista información disponible.

### RF-06 Alertas
Mostrar y administrar alertas generadas por reglas o detecciones.

### RF-07 Configuración
Permitir administrar parámetros básicos del sistema.

## Requisitos no funcionales

- Interfaz responsive.
- Código mantenible.
- Tipado estricto.
- Manejo adecuado de errores.
- Seguridad de secretos mediante variables de entorno.
- Arquitectura preparada para crecimiento.
- Trazabilidad de decisiones técnicas.
